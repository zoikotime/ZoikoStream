## Access profiles
Every event has one visibility setting:
- Public — anyone with the event page can register and watch.
- Unlisted — not listed; anyone with the link can register and watch.
- Private — only invited people, holders of a valid access link, or members of your organization can watch.
Public and unlisted events always ask viewers to register before watching.

## Registration
Registration can be required, and a registration limit caps the number of sign-ups. When registrations reach the limit the event is at capacity and new registrations are refused.

## Access links
Access links let people into a private event without an individual invitation. A link can have a label and an expiry, and it records how often it was used. You can rotate a link (the old link stops working and a new one is issued) or revoke it (it stops working). Link secrets are shown only once when the link is created or rotated; Guide never displays them.

## Invitations
Invited viewers receive a personal link. A personal invitation can be claimed on one device; using it elsewhere is refused.

## Admission capacity
The platform holds new viewers in a queue once the viewing capacity is reached and admits them automatically as room frees up. It never removes someone already watching.

## Refused joins
The platform records why a join was refused: invalid invite, invalid link, invite used elsewhere, not invited, event full, at capacity, event cancelled, event unavailable, or removed by host.

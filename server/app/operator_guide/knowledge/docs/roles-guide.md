## Roles
- Organization admin — manages the organization: users, billing, developer settings, every event.
- Host — runs events they created or are assigned to.
- Speaker — contributes to events they are invited to.
- Viewer — watches events.
Guide is available to hosts and organization admins.

## What Guide can do
Guide explains your events, readiness, audience access, recordings and replay, live health, analytics, planning and the developer platform, using the same permissions you have. It can draft text, make low-risk changes after you confirm them, and open the right page for anything else.

## How Guide handles changes
- Reading and analysis happen directly.
- Drafts are created only as drafts.
- Low-risk changes (for example turning chat on or off) need your explicit confirmation and return a receipt.
- Material changes (for example making an event private or revoking an access link) need permission, explicit confirmation and are audited.
- Critical live controls (go live, end broadcast, failover, hard overrides) open the dedicated control instead.
- Destructive or security-sensitive operations (deleting media or events, secrets) are never done through Guide.

## Guide settings
Organization admins can turn Guide on or off and choose which capabilities it may use: documentation answers, event-state analysis, analytics explanation, drafts and approved low-risk actions. Auditing and confirmation for changes are always on.

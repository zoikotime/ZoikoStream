# Viewer Help: Language and Read Aloud

## Languages on the event page

The event page has a "Language" picker with these languages:

- English
- Español
- Français
- Deutsch
- Português
- हिन्दी (Hindi)

## Changing the language

Use the "Language" picker in the event page header (on a phone, just below the header).

## Read aloud

The "Read aloud" button reads the instruction the page is currently showing, in the selected language. Select "Stop reading" to stop.

## Event times

Before an event starts, the page shows the start time in your own time zone and in UTC.

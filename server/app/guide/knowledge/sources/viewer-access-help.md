# Viewer Help: Joining and Accessing an Event

## Where viewers watch

Viewers watch an event on its event page, which opens from the event link or invitation link they were sent.

## Entering your name to watch

Some events ask for your name before you can watch. The page shows "Enter Your Name" and "Enter your name to watch the live event."

1. Enter your full name.
2. Optionally check "Remember me for this event" to skip this form next time on this device.
3. Select "Continue to Watch".

The page may instead offer "Continue as" followed by your name. Select "Continue", or select "Not you? Change details" to enter different details.

While a saved registration is being checked, the page shows "Checking your registration…".

## When an event is full

If registration has reached capacity, the page shows "This event is full" and says that registration for the event has reached capacity.

## When the event is very busy

If the event is very busy, the page shows "This event is very busy right now" and "You'll join automatically as soon as there's room. Please keep this page open." It counts down to the next automatic attempt ("Trying again in" a number of seconds). You can also select "Try now".

## Before the event starts

If you open the page before the event has started, it shows "The service hasn't started yet", the event title, the start time in your own time zone and in UTC, and "Service will begin here automatically."

## When the viewing time has closed

If the scheduled viewing time is over, the page shows "This event has ended" and "The scheduled viewing time for this event has closed."

## Cancelled events

If an event was cancelled, the page shows "This event was cancelled" and says the event won't take place and there's nothing to watch.

## If you are removed from an event

If you are removed from an event, the page shows "You've left this event" with the reason.

## Invalid invitation links

If an invitation link isn't valid, the page shows "This invitation link isn't valid. You can still continue below."

## Opening the page inside another app

If you open the event page inside another app's built-in browser, the page shows "For the best experience, open this page in your browser."

- On iPhone or iPad: tap the menu (⋯ or the share button) and choose "Open in browser".
- On Android: tap the menu (⋮) and choose "Open in browser", or use the "Open in browser" button.
- You can also select "Copy link" and paste the link into your browser.
- If you were sent a private invitation, open the original invitation link in your browser.

## Event addresses that only host event pages

Some organizations use their own web address for events. That address only hosts event pages. If you open any other page there, it shows "Page not available": open the event link you were sent to watch.

## If the event cannot be found

If the event cannot be found, the page shows "This event could not be found."

## If the event page will not load

If the page cannot load the event, it shows "We couldn't load this event" and "Please check your connection and try again."

1. Select "Try again".
2. If the problem continues, select "Contact support" to open the contact page (/contact).
3. Select "Service status" to open the status page (/status).
